# Roadmap

Дорожная карта разработки по этапам, от базовой инфраструктуры до MVP и дальнейших улучшений. Порядок последовательный — этапы без явных зависимостей от следующих можно частично распараллелить, но рекомендуется двигаться сверху вниз.

## Milestone 0 — Подготовка

- [ ] Инициализация Go-модуля, структура проекта (`cmd/`, `internal/handlers`, `internal/services`, `internal/storage`)
- [ ] Инициализация Android Viewer App проекта (Kotlin, минимальный шаблон)
- [ ] Настройка SQLite и системы миграций (например, `golang-migrate` или `goose`)

## Milestone 1 — Авторизация пользователей

- [ ] Регистрация и логин по логину + паролю, хэширование паролей (bcrypt/argon2)
- [ ] Выдача JWT access + refresh, эндпоинт обновления токена
- [ ] Логаут и отзыв refresh-токена
- [ ] Таблицы `users`, `refresh_tokens`

## Milestone 2 — Устройства и токены

- [ ] CRUD для `devices`: регистрация устройства-шлюза
- [ ] Генерация, ревокация и перевыпуск `upload_token`
- [ ] `viewer_bindings`: выдача и отзыв `download_token` для привязки просматривающих аккаунтов к устройству

## Milestone 3 — Приём SMS (webhook)

- [ ] Эндпоинт приёма webhook от Gateway App: валидация `upload_token`
- [ ] Опциональная проверка подписи `X-Signature` (HMAC-SHA256)
- [ ] Дедупликация повторных доставок (Gateway App повторяет отправку до 10 раз)
- [ ] Сохранение сообщений в `messages`
- [ ] Ручное end-to-end тестирование с реальным приложением-шлюзом на устройстве

## Milestone 4 — REST API для просмотра

- [ ] Список устройств, доступных текущему пользователю
- [ ] Список сообщений по устройству с пагинацией и фильтрацией

## Milestone 5 — Realtime-доставка

- [ ] WebSocket (или SSE) эндпоинт для push новых сообщений подписанным клиентам
- [ ] Fallback на REST-поллинг при разрыве соединения

## Milestone 6 — Android Viewer App (MVP)

- [ ] Экран логина
- [ ] Список привязанных устройств
- [ ] Добавление устройства по `download_token` (ручной ввод / QR-код)
- [ ] Лента сообщений с realtime-обновлением

## Milestone 7 — Безопасность и эксплуатация

- [ ] Rate-limiting на webhook-эндпоинт
- [ ] HTTPS/TLS в деплое, Docker-контейнеризация бэкенда
- [ ] Логирование и health-check эндпоинт

## Milestone 8 — Backlog (пост-MVP, не приоритизировано)

- [ ] Миграция хранилища на PostgreSQL
- [ ] Push-уведомления (FCM) в Viewer App
- [ ] Поиск по тексту сообщений, экспорт истории
- [ ] Web-версия просмотрщика
- [ ] Раздельное управление несколькими SIM-слотами на одном устройстве
